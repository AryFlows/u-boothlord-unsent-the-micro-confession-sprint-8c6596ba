A two-part micro-confession for Unsent: The Micro-Confession Sprint — a `To:` line naming who it was meant for, and the one line that was typed and never sent. The message stayed in drafts because some silences are easier to keep than to explain.

## Run it

```sh
node main.ts
```

Writes the confession to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
